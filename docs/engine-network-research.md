# Поиск игрового ядра и клиента

Проверено 4 ноября 2026 года. Кэш и текстуры на этом этапе отложены.

## Результат поиска

Найдены открытые реализации игровой логики GTA SA и сетевого клиента SA-MP. Готовой проверенной основы, которая одновременно работает на iOS и совместима с текущим Arizona Mobile, среди проверенных проектов не обнаружено.

Нужны две независимые части: переносимое игровое ядро и протокол Arizona. Наиболее конкретная основа для транспорта — `mishpro-programm/sampraknet`. Для независимой игровой логики найдены SanAndreasUnity и OpenSA; они используют другие runtime и не предоставляют готовую интеграцию с Arizona.

## Где логика в нашем APK

`libag-client.so` содержит JNI Init/Step/Pause/Resume, ввод, HUD, следы librw, UDP и Boost.Asio. Отдельной libGTASA.so нет. По этим признакам основная игровая реализация находится в объединённом нативном модуле; границы всех внутренних подсистем не восстановлены.

В release-библиотеке отсутствует обычная .symtab. Динамические экспорты раскрывают Android-мост, но не внутренние CGame/CNetGame/RPC-таблицы. Исходники libag-client по выполненному поиску не найдены. Совпадение имени движка/транспорта не является доказательством совпадения реализации.

Точная версия протокола Arizona, собственные RPC, handshake, проверка клиента и расширенная синхронизация пока не установлены. Не выполнялись запуск APK, попытки авторизации или подключения к боевым игровым серверам.

## Найденный iOS-клиент

[Страница автора ALYN](https://alynsampmobile.pro/download/ios) на момент проверки указывает закрытую ReSA-бету, установку для зарегистрированных тестеров и отсутствие загруженной iOS-сборки. Сторонние зеркала с более старыми IPA не дают исходников и не подтверждают текущую доступность или Arizona-совместимость.

Android-источник ALYN 17.x и iOS ReSA нельзя считать одним исходным проектом. Регистрация тестеров/устройств не обходилась; сообщения авторам от имени пользователя не отправлялись.

## Следующий проверяемый шаг

Добавлен `NetworkProbe/` и отдельный workflow **SA-MP transport iOS portability**. Он получает фиксированный sampraknet commit, компилирует и связывает библиотеку с маленькой собственной программой для iPhone ARM64 и Simulator x86_64. Проверяются размеры ID и legacy timestamp. Программа не запускается, игровой протокол с серверами не используется. В артефакты попадают только логи; библиотека не включена в приложение.

Результат первого запуска будет зафиксирован по фактической сборке. Пока переносимость не считается подтверждённой. Сборка не является аудитом лицензий или проверкой сетевой совместимости.

После этого нужны: подтверждение протокола Arizona на разрешённой трассе/тестовом сервере; выбор игрового backend; связывание RPC с игроками, транспортом и объектами. Для игрового backend наиболее прямой путь — исходники владельцев Arizona; независимый движок — отдельная большая реализация поведения игры.

Источник по происхождению sampraknet: [OpenSAMP THIRD-PARTY-NOTICES](https://github.com/bssth/opensamp/blob/a05717eeab2de65d1def7e7725dc1985198400f7/THIRD-PARTY-NOTICES.md). Проблемы лицензий отдельных добавлений записаны, а не предполагаются решёнными наличием публичного репозитория.
